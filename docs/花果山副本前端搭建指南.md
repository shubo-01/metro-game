# 花果山副本前端搭建指南（Cocos Creator 3.8）

> 本文档为 Qoder Work 级别的可执行搭建步骤，可在 Cocos Creator 编辑器中按顺序执行。
> 严格对齐《花果山副本设计文档 V3》和《花果山副本技术方案》。

---

## 一、全局准备

### 1.1 脚本文件确认

确保 `frontend/assets/scripts/` 下已存在以下文件：

| 路径 | 职责 |
|------|------|
| `net/DungeonApi.ts` | 副本 + 牢结值 API 客户端、枚举、类型定义 |
| `ui/HuaguoshanEntryUI.ts` | 花果山入口面板组件 |
| `ui/HuaguoshanSettleUI.ts` | 花果山结算面板组件 |
| `common/Constants.ts` | 已添加 `DEV_DUNGEON_URL` 端口 8007 |
| `net/HttpClient.ts` | 已添加 `/dungeon/*`、`/fatigue/*` 路由 |

### 1.2 全局 SceneName 扩展（可选）

如果需要把花果山战斗做成独立 Cocos 场景，可在 `SceneManager.ts` 中追加：

```ts
export enum SceneName {
    // ... 现有
    HuaguoshanBattle = 'HuaguoshanBattle',
}
```

当前方案使用弹窗面板（overlay），无需新场景。

## 二、花果山入口面板（HuaguoshanEntryUI）

### 2.1 创建 Prefab

1. **Cocos Creator → 资源管理器** → `assets/prefabs/ui/` 目录右键 → **创建 → Prefab**

## 四、花果山战斗场景逻辑（集成到 Hall 或独立场景）

### 4.1 推荐方案：Overlay 模式

不新建 Cocos Scene，而是在 Hall 场景中用一个全屏容器节点模拟副本战斗：

```
Canvas
├── HallWorldLayer (进入副本时 active=false)
├── HuaguoshanBattleLayer (active=false, 进入副本时激活)
│   ├── BattleBg (Sprite: 花果山背景)
│   ├── EntityContainer (角色/Boss/猴子/效果)
│   ├── HUD
│   │   ├── TimerLabel (Label: 倒计时 "5:00")
│   │   ├── HpBar (ProgressBar: 血条)
│   │   ├── ObserveBar (ProgressBar: 观测度, 仅草木显示)
│   │   └── RoleNameLabel (Label: 当前身份名)
│   └── EventButtons (仅草木显示: 观测事件上报按钮)
├── HuaguoshanEntryPanel (Prefab)
└── HuaguoshanSettlePanel (Prefab)
```

### 4.2 战斗流程脚本（需新建）

建议创建 `frontend/assets/scripts/scene/Huaguoshan/HuaguoshanBattle.ts`：

```ts
@ccclass('HuaguoshanBattle')
export class HuaguoshanBattle extends Component {
    // 监听 HuaguoshanEvent.ENTER → 显示战斗层
    // 根据 role_type 初始化不同角色操作
    // 定时器 300 秒倒计时
    // 心跳上报 fatigue/consume（每60秒）
    // 草木石头：显示观测事件按钮
    // 大圣/魔王：战斗操作（简化 AI 或手动操作）
    // 时间到 / HP=0 → 调用 DungeonApi.settle() → emit SETTLE
}
```

### 4.3 牢结值心跳消耗

在战斗场景中每 60 秒调用一次：

```ts
this.schedule(() => {
    DungeonApi.consumeFatigue(this._playerId, 60);
}, 60);
```

```

└── MowangDeathBtn   (Button: "魔王死亡 +15%")
```

### 5.2 事件代码

```ts
private _onObserveEvent(eventCode: HgsObserveEvent) {
    DungeonApi.reportObserve(this._sessionId, this._playerId, eventCode).then(res => {
        if (res.code === 0) {
            this._observeScore = res.data!.observe_score;
            this._updateObserveBar();
        }
    });
}
```

## 六、打坐恢复入口

### 6.1 推荐位置

在大厅 HallUI 的快捷操作栏 `quickActions` 中已有"修炼"按钮，可复用或新增"打坐"按钮。

### 6.2 逻辑

```ts
// 开始打坐
await DungeonApi.startMeditate(playerId);
// ... 播放打坐动画（角色坐下）...
// 结束打坐（玩家点击或自动触发）
const res = await DungeonApi.endMeditate(playerId);
// res.data.recover_sec = 打坐时长×2 的恢复量
```

## 七、SceneManager 场景流转

```
Login → CharacterCreate → Hall
                            ↓
                    [点击"副本"入口]
                            ↓
                  HuaguoshanEntryPanel (概率/牢结值预览)
                            ↓ [进入]
                  HuaguoshanBattleLayer (激活战斗)
                            ↓ [5分钟到/HP=0/客户端上报结算]
                    settle() → HuaguoshanSettlePanel
                            ↓ [确认]
                    返回 HallWorldLayer
```

## 十、Cocos Creator 编辑器操作步骤汇总

### Step 1：导入脚本
1. 打开 Cocos Creator 项目（`frontend/` 目录）
2. 等待 TS 自动编译完成（底部状态栏无红色报错）
3. 确认 `assets/scripts/net/DungeonApi.ts`、`assets/scripts/ui/HuaguoshanEntryUI.ts`、`assets/scripts/ui/HuaguoshanSettleUI.ts` 在资源管理器中可见

### Step 2：创建入口面板 Prefab
1. 右键 `assets/prefabs/ui/` → 创建 → Node → 空节点
2. 按照第二章节点树逐层创建子节点
3. 为每个 Label 设置字号、颜色
4. 为按钮添加 Button 组件 + Sprite（圆角背景）
5. 根节点添加 `HuaguoshanEntryUI` 脚本，拖拽绑定
6. 将根节点拖入 `assets/prefabs/ui/` 生成 Prefab
7. 删除场景中临时节点

### Step 3：创建结算面板 Prefab
1. 同上流程，按第三章节点树创建
2. 根节点添加 `HuaguoshanSettleUI` 脚本，拖拽绑定
3. 保存 Prefab

### Step 4：在 Hall 场景挂载
1. 打开 Hall 场景
2. 将两个 Prefab 拖入 Canvas 层级末尾
3. 设置 `active = false`
4. 在 HallUI 的"副本"入口按钮点击事件中加入：
   ```ts
   this.huaguoshanEntryPanel.active = true;
   ```

### Step 5：创建战斗层
1. 在 Hall 场景 Canvas 下新建空节点 `HuaguoshanBattleLayer`
2. 添加 Sprite 子节点作为背景
3. 添加 EntityContainer、HUD、EventButtons 子节点
4. 默认 `active = false`

### Step 6：联调验证
1. 启动 dungeon-service（`go run ./cmd/dungeon-service`）
2. 在 Cocos Creator 中运行 Web 预览
3. 进入大厅 → 点击"副本" → 查看概率/牢结值
4. 点击"进入副本" → 观察分配身份
5. 等待 5 分钟或手动触发结算 → 查看结算面板
