## 一、项目结构总览

### 1.1 前端文件分布

```
frontend/
├── assets/
│   ├── scenes/
│   │   ├── Login.scene              # 登录场景
│   │   ├── CharacterCreate.scene    # 角色创建场景
│   │   └── Hall.scene               # 大厅场景（本次UI挂载到此场景）
│   └── scripts/
│       ├── GameManager.ts           # 全局管理器（常驻节点）
│       ├── common/Constants.ts      # 全局常量
│       ├── manager/
│       │   ├── PlayerManager.ts     # 玩家数据管理
│       │   ├── TokenManager.ts      # Token 管理
│       │   ├── EventManager.ts      # 事件总线
│       │   └── SceneManager.ts      # 场景切换
│       ├── net/
│       │   ├── HttpClient.ts        # HTTP 请求封装
│       │   └── WsClient.ts          # WebSocket 封装
│       ├── scene/Hall/
│       │   ├── HallScene.ts         # 大厅场景主逻辑
│       │   ├── HallUI.ts            # 大厅基础 UI
│       │   ├── PlayerEntity.ts      # 玩家实体
│       │   └── NPCEntity.ts         # NPC 实体
│       └── ui/                      # ★ 本次新增 6 个 UI 模块
│           ├── CharacterPanel.ts     # 角色面板
│           ├── RealmBreakthroughUI.ts # 境界突破
│           ├── DeathChoiceUI.ts     # 死亡选择
│           ├── PossessUI.ts         # 夺舍界面
│           ├── BeastTransformUI.ts  # 兽身化形
│           └── PublicEnemyIndicator.ts # 公敌指示器
└── tsconfig.json
```

### 1.2 已有脚本核心约定

| 约定 | 说明 |
|------|------|
| 角色 ID 获取 | `PlayerManager.playerId`（不是 TokenManager） |
| HTTP 请求 | `HttpClient.get(path)` / `HttpClient.post(path, body)` |
| 事件通信 | `EventManager.on(GameEvent.XXX, callback, this)` |
| 场景切换 | `SceneManager.loadScene(SceneName.Hall)` |
| 进度条 | 用 `@property(Node)` + `(node as any).progress` 访问 |
| 主题色 | `ThemeColor.GOLD / TEXT_WHITE / DANGER` 等 |

### 1.3 后端接口地址

开发环境基础地址：`http://127.0.0.1:8001`（auth-service）

| 服务 | 端口 | 路由前缀 |
|------|------|----------|
| 认证服务 | 8001 | `/auth/*` |
| 角色服务(旧) | 8002 | `/player/*` |
| 场景服务 | 8003 | `/scene/*` |
| 会话服务 | 8004 | `/session/*` |
| **角色系统(新)** | **8005** | `/character/*` |
| **死亡系统(新)** | **8006** | `/death/*` |

> **重要：** `HttpClient` 默认 base_url 是 `http://127.0.0.1:8001`。  
> 人物系统的 `/character/*` 和 `/death/*` 接口分别在 8005 和 8006 端口。  
> 需要在 `Constants.ts` 中更新 `DEV_HTTP_URL` 或配置网关代理。  
> 建议方案：增加多 base_url 支持（见第十节）。

## 三、CharacterPanel 角色面板搭建

### 3.1 创建节点树

在 `Canvas > UILayer` 下新建节点，结构如下：

```
UILayer
└── CharacterPanel                    ← 空节点，挂载 CharacterPanel 脚本
    ├── Title (Label)                 ← "角色面板"
    ├── CloseBtn (Node+Button)        ← 关闭按钮
    ├── Content (Layout)              ← 内容容器（垂直布局）
    │   ├── BaseAttrsGroup (Node)     ← 五维属性区
    │   │   ├── JingLabel (Label)     ← 精属性
    │   │   ├── QiLabel (Label)       ← 气属性
    │   │   ├── ShenLabel (Label)     ← 神属性
    │   │   ├── QiYunLabel (Label)    ← 气运
    │   │   └── WuXingLabel (Label)   ← 悟性
    │   ├── DerivedGroup (Node)       ← 衍生属性区
    │   │   ├── HpLabel (Label)       ← 气血
    │   │   ├── MpLabel (Label)       ← 灵力
    │   │   ├── SoulLabel (Label)     ← 魂力
    │   │   ├── PhysiqueLabel (Label) ← 体魄
    │   │   ├── AgilityLabel (Label)  ← 身法
    │   │   ├── SkillPowerLabel (Label)← 功法威力
    │   │   └── SenseRangeLabel (Label)← 神识范围
    │   ├── RealmGroup (Node)         ← 境界信息区
    │   │   ├── RealmLabel (Label)    ← 境界名称
    │   │   ├── ExpProgressBar (ProgressBar) ← 经验进度条
    │   │   └── ExpLabel (Label)      ← "200/100"
    │   ├── QiGroup (Node)            ← 五行修炼区
    │   │   ├── ElementCountLabel (Label)  ← 兼修数量
    │   │   ├── ExpMultLabel (Label)       ← 经验倍率
    │   │   ├── DmgMultLabel (Label)       ← 伤害倍率
    │   │   └── MultiplierInfoLabel (Label)← 修炼详情
    │   └── HiddenGroup (Node)        ← 隐藏属性区
    │       ├── XinmoLabel (Label)    ← 心魔
    │       ├── KarmaLabel (Label)    ← 因果
    │       └── DaoXingLabel (Label)  ← 道行
    └── ToastLabel (Label)            ← 提示消息（默认隐藏）
```

### 3.2 创建节点操作步骤

**在 Cocos Creator 层级管理器中：**

1. **右键 `UILayer`** → 创建 → 空节点 → 命名 `CharacterPanel`
2. **右键 `CharacterPanel`** → 创建 → UI → Label → 命名 `Title`
   - String: `角色面板`
   - FontSize: 28
   - Color: `#D4A843`（金色）
3. **右键 `CharacterPanel`** → 创建 → UI → Button → 命名 `CloseBtn`
   - 子节点 Label String: `✕`
4. **右键 `CharacterPanel`** → 创建 → 空节点 → 命名 `Content`
   - 添加 `Layout` 组件 → Type: `VERTICAL`，SpacingY: `10`
5. 在 `Content` 下依次创建上述所有子节点

### 3.3 节点属性设置

**CharacterPanel 根节点：**
- Widget 组件：Top=20, Left=20, Bottom=20, Right=自适应（面板宽度400）
- 添加 `Sprite` 组件 → Type: SLICED，SpriteFrame: 默认白色精灵
- Color: `#16213e`（暗色面板背景 `ThemeColor.BG_PANEL`）

**五维属性 Label 节点（示例 JingLabel）：**
- String: `精: 1`
- FontSize: 20
- Color: `#F5F5F5`（`ThemeColor.TEXT_WHITE`）
- Overflow: CLAMP

**ExpProgressBar 节点：**
- 创建 → UI → ProgressBar
- TotalLength: 300
- Progress: 0
- BarSprite Color: `#D4A843`（金色）
- Background Color: `#2A2A4A`（`ThemeColor.BORDER`）

**ToastLabel 节点：**
- String: (空)
- FontSize: 18
- Color: `#2ECC71`
- 节点 **取消勾选 Active**（默认隐藏）

### 3.4 挂载脚本 + Inspector 绑定

1. **选中 `CharacterPanel` 节点**
2. **添加组件** → 搜索 `CharacterPanel` → 添加
3. 在 Inspector 面板中逐一绑定属性：

| Inspector 属性 | 拖入节点 |
|---|---|
| `jingLabel` | Content > BaseAttrsGroup > JingLabel |
| `qiLabel` | Content > BaseAttrsGroup > QiLabel |
| `shenLabel` | Content > BaseAttrsGroup > ShenLabel |
| `qiYunLabel` | Content > BaseAttrsGroup > QiYunLabel |
| `wuXingLabel` | Content > BaseAttrsGroup > WuXingLabel |
| `hpLabel` | Content > DerivedGroup > HpLabel |
| `mpLabel` | Content > DerivedGroup > MpLabel |
| `soulLabel` | Content > DerivedGroup > SoulLabel |
| `physiqueLabel` | Content > DerivedGroup > PhysiqueLabel |
| `agilityLabel` | Content > DerivedGroup > AgilityLabel |
| `skillPowerLabel` | Content > DerivedGroup > SkillPowerLabel |
| `senseRangeLabel` | Content > DerivedGroup > SenseRangeLabel |
| `realmLabel` | Content > RealmGroup > RealmLabel |
| `expProgressBar` | Content > RealmGroup > ExpProgressBar |
| `expLabel` | Content > RealmGroup > ExpLabel |
| `elementCountLabel` | Content > QiGroup > ElementCountLabel |
| `expMultiplierLabel` | Content > QiGroup > ExpMultLabel |
| `damageMultiplierLabel` | Content > QiGroup > DmgMultLabel |

| `karmaLabel` | Content > HiddenGroup > KarmaLabel |

### 3.5 关闭按钮事件

1. 选中 `CloseBtn` 节点
2. Inspector → Button → Click Events → 添加事件
3. 目标节点拖入 `CharacterPanel`
4. 组件选择 `CharacterPanel`
5. 方法选择 `node` → `active` → 取消勾选（隐藏面板）

> 或者在 HallScene.ts 中通过代码控制 `CharacterPanel` 节点的 `active` 属性。

### 10.2 更新 HttpClient 支持多 base_url

**修改文件：** `frontend/assets/scripts/net/HttpClient.ts`

在 `HttpClient` 类中添加多 base_url 支持：

```typescript
/** 带自定义 base_url 的 GET */
static async getFrom<T = any>(baseUrl: string, path: string, params?: Record<string, string>): Promise<ApiResponse<T>> {
    let url = `${baseUrl}${path}`;
    if (params) {
        const qs = Object.entries(params).map(([k, v]) => `${k}=${encodeURIComponent(v)}`).join('&');
        url += `?${qs}`;
    }
    return HttpClient._request<T>(url, 'GET');
}

/** 带自定义 base_url 的 POST */
static async postTo<T = any>(baseUrl: string, path: string, body?: any): Promise<ApiResponse<T>> {
    const url = `${baseUrl}${path}`;
    return HttpClient._request<T>(url, 'POST', body);
}
```

### 10.3 UI 脚本中使用多 base_url

## 附录：常见问题

### A1: 添加脚本后 Inspector 不显示属性

**原因：** Cocos Creator 未正确编译 TypeScript  
**解决：** 点击菜单 → 开发者 → 重新编译脚本，或重启编辑器

### A2: ProgressBar 属性无法拖入

**原因：** `expProgressBar` 声明为 `@property(Node)` 而非 `@property(ProgressBar)`  
**解决：** 直接拖入 ProgressBar 节点即可，Node 类型接受任何节点

### A3: 面板打开后空白无数据

**原因：** 后端服务未运行，或 HttpClient base_url 不匹配  
**解决：**
1. 确认 character-service (8005) 和 death-service (8006) 已启动
2. 确认 Constants.ts 中的 DEV_CHARACTER_URL / DEV_DEATH_URL 正确
3. 检查浏览器控制台网络请求是否 404

### A4: 按钮点击无反应

**原因：** 按钮节点缺少 `Button` 组件，或 `TOUCH_END` 事件未绑定  
**解决：** 确认按钮节点有 `Button` + `UITransform` 组件

### A5: 多个面板重叠遮挡

**解决：** 为每个面板根节点设置不同的 `Sibling Index`（层级顺序），或使用 `BlockInputEvents` 组件阻止穿透点击
