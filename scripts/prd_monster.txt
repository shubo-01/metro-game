# 第一部分：产品设计文档
## 一、系统总述
初始之地是寻仙世界中最诡异、最神秘之地，也是最难探索的区域。玩家从中心城镇出发，进入初始之地自由探索，遇到各类野怪。野怪以族群形式分布，每个族群有固定领地边界，族群内分为普通怪、精英怪、Boss怪、妖、神兽五类。离城镇越远怪物等级越高，初始之地外围是玩家接触的第一层。
## 二、初始之地区域划分

| 区域 | 内容 | 难度 |
| 外围 | 普通怪、精英怪、Boss怪集中地，少部分妖 | ★★ |
| 中心地带 | 都是Boss怪，少部分妖 | ★★★ |
| 核心地带 | Boss怪、大部分妖和妖幼崽聚集地 | ★★★★ |
| 妖殿 | 神兽和神兽幼崽聚集地，超标妖聚集地 | ★★★★★ |

## 三、族群结构
外围共有100个不同族群，每个族群结构如下：

| 类型 | 数量/族群 | 等级范围 | 备注 |
| 普通怪 | 50只 | 人一阶~人三阶 | 属性随机分配五行 |
| 精英怪 | 10只 | 人一阶~人三阶 | 属性随机分配五行 |
| Boss怪 | 2只 | 人一阶~人三阶 | 属性随机分配五行 |
| 妖 | 1只 | 人一阶~人三阶 | 四修模板 |
| 妖幼崽 | 若干 | 人五阶（属性=妖的2/3） | 可抓捕，被抓后刷新 |
| 神兽 | 毅5族群共享1只 | 人九阶 | 五修模板，唯一性，不刷新 |
| 神兽幼崽 | 随神兽 | 人五阶（属性=神兽的2/3） | 可抓捕，唯一性，不刷新 |

全100族群 = 20只神兽，分布在外围边缘与妖殿入口附近。神兽随机出现在5个族群中的1个领地内。族群之间有领地边界，不串场。

## 五、协战围攻系统
怪物可以合作打玩家。当多个怪物同时围攻玩家时，根据围攻数量和属性组合触发伤害倍率：

| 围攻数 | 同属性伤害倍率 | 五行相生叠加伤害倍率 |
| 3个 | ×1.5 | ×2.0 |
| 4个 | ×2.0 | ×3.0 |
| 5个 | ×3.0 | ×5.0 |
| 7个 | ×4.0 | ×10.0 |

五行相生顺序：金生水、水生木、木生火、火生土、土生金。当围攻怪物的属性按相生顺序排列时，触发相生叠加倍率。蛮蛮（比翼鸟）特殊机制：永远成对出现，协战倍率翻倍。
## 六、抓捕系统
抓捕条件：妖幼崽或神兽幼崽血量降至30%以下
抓捕方式：使用抓捕道具或抓捕技能
抓捕成功率：受目标血量、抓捕道具品质、玩家抓捕等级影响
妖幼崽：被抓后有CD刷新，可重复抓捕
神兽幼崽：唯一性，被抓后不刷新，全服仅一只
抓捕后用途：可作为宠物或坐骑

### 4.1 属性模板计算公式

func CalcMonsterAttr(baseAttr PlayerAttr, monsterType MonsterType, tier int) MonsterAttr {
  var multi float64
  switch monsterType {
  case NORMAL: multi = normalMultiplier(tier) // 1.5/1.5/2.0/2.0...
  case ELITE:  multi = eliteMultiplier(tier)  // 2.0/2.5/3.0/3.0...
  case BOSS:   multi = bossMultiplier(tier)    // 3.0/3.5/4.0/4.0...
  case YAO:    multi = yaoMultiplier(tier)     // 3.0/3.5/4.0/4.0...
  case DIVINE: multi = divineMultiplier(tier)  // 5.0/2.0/3.0/3.0...
  }
  return baseAttr.ScaleBy(monsterType.CultCount(), multi)
}
### 4.2 协战倍率计算
Go伪代码：
func CoopDamageMultiplier(surrounders []Monster) float64 {
  n := len(surrounders)
  sameElem := allSameElement(surrounders)
  shengCycle := isWuxingSheng(surrounders)
  switch {
  case n >= 7 && shengCycle: return 10.0
  case n >= 7 && sameElem:    return 4.0
  case n >= 5 && shengCycle: return 5.0
  case n >= 5 && sameElem:    return 3.0
  case n >= 4 && shengCycle: return 3.0
  case n >= 4 && sameElem:    return 2.0
  case n >= 3 && shengCycle: return 2.0
  case n >= 3 && sameElem:    return 1.5
  }
  return 1.0
}
### 4.3 蛮蛮特殊机制
蛮蛮（比翼鸟）永远成对出现，协战倍率翻倍。在计算协战倍率后，如果其中含蛮蛮对，最终倍率×2。

## 六、抓捕系统技术方案
### 6.1 抓捕流程
Go伪代码：
func AttemptCapture(playerID int64, targetID int64, itemID int) (*CaptureResult, error) {
  target := monsterService.GetEntity(targetID)
  if target == nil || !isCapturable(target) {
    return nil, ErrNotCapturable
  }
  if target.HPPercent() > 0.3 {
    return nil, ErrHPTooHigh
  }
  // Divine beast cub: check uniqueness
  if target.Type == DIVINE_CUB && divineBeastCaptured(target.FactionGroup) {
    return nil, ErrAlreadyCaptured
  }
  rate := calcCaptureRate(target, itemID, playerService.GetCaptureLevel(playerID))
  if rand.Float64() > rate {
    return &CaptureResult{Success: false}, nil
  }
  // Success
  if target.Type == YAO_CUB {
    monsterService.SetRespawnTimer(target.FactionID, YAO_CUB_CD)
  } else {
    monsterService.MarkCaptured(targetID) // permanent
  }
  inventoryService.AddPet(playerID, target.SpeciesID, target.Element)
  return &CaptureResult{Success: true}, nil
}
### 6.2 抓捕成功率公式
captureRate = baseRate × itemMultiplier × levelMultiplier × hpFactor
baseRate = 0.3（基础成功率）
itemMultiplier：抓捕道具品质，普通×1.0 / 稀有×1.5 / 传说×2.0
levelMultiplier：玩家抓捕技能等级加成
hpFactor = (1 - targetHPPercent) / 0.7，血量越低成功率越高
