[P12][Heading 2] 1.1 副本背景
[P13][] 花果山水帘洞被混世魔王强占，孙悟空归来后发现家园被侵占，逐驱混世魔王夺回水帘洞。这是寻仙的第一个场景副本，也是玩家接触游戏核心玩法的起点。
[P14][Heading 2] 1.2 核心玩法：随机身份入场
[P15][] 玩家从花果山地图位置进入场景后，系统按概率随机将玩家变成场景中的某个角色。变成谁就玩谁的玩法，目标各不相同。每次进场体验都不一样，可能这把你是大圣三阶段打Boss，下把你就变成一只普通猴子想办法多活几秒。
[P16][Heading 2] 1.3 场景角色一览
[P17][Heading 2] 1.4 进出场景
[P18][List Paragraph] 玩家从花果山地图位置进入，出来后回到进入位置
[P19][List Paragraph] 进入次数与玩家牢结值绑定，不单独限制次数
[P20][List Paragraph] 牢结值耗尽后不可进入副本，需恢复后再进
[P21][Heading 1] 2. 运气机制
[P22][Heading 2] 2.1 基本规则
[P23][] 运气只提升稀有角色（孙悟空和混世魔王）的中奖率，多出的概率从魔王手下、普通猴子、老猴子、草木石头四个角色按比例扣除，总量保持1.0。
[P24][Heading 2] 2.2 公式
[P25][] 当运气 = 0 时：使用基础概率。
[P26][] 当运气 > 0 时：
[P27][List Paragraph] 孙悟空最终概率 = 0.01 × (1 + 运气)
[P28][List Paragraph] 混世魔王最终概率 = 0.09 × (1 + 运气)
[P29][List Paragraph] 多出的概率 = (孙悟空最终 - 0.01) + (魔王最终 - 0.09)，从魔王手下、普通猴子、老猴子、草木石头按比例扣除
[P30][List Paragraph] 各角色扣除量 = 多出概率 × (该角色原概率 / 四者原概率总和0.90)
[P31][Heading 2] 2.3 示例计算（运气 = 0.2）

[P95][Heading 1] 11. 副本流程
[P96][Heading 2] 11.1 进场流程
[P97][] 玩家在地图上接近花果山入口 → 点击进入 → 系统检查牢结值 → 牢结值>0则进入 → 运气加权计算各角色概率 → 随机判定身份 → 加载对应玩法。
[P98][Heading 2] 11.2 战斗流程
[P99][] 根据变成的角色不同，进入不同的战斗模式：
[P100][List Paragraph] 孙悟空：实时动作战斗，操作技能打Boss，直至一方死亡
[P101][List Paragraph] 混世魔王：实时动作防御，操1AI大圣攻击5分钟，操1满触发剧情死亡
[P102][List Paragraph] 魔王手下/普通猴子/老猴子：生存模式，在混乱中求生5分钟
[P103][List Paragraph] 草木石头：观测模式，旁观AI大圣打魔王，观测度累加5分钟
[P104][Heading 2] 11.3 结算流程
[P105][] 角色死亡/时间到 → 结算画面 → 评级评定（S/A/B/C/D） → 随机评语 → 奖励发放 → 回到花果山地图位置。
